# Plan: Wrap NeWWorld-Config-Manager in uv and Improve UI

## Project Overview
This is a PyQt6 desktop application for editing New World game config files (rebindings_*.xml, usersettings.javsave).

## Goals
1. Wrap the project in uv for Python dependency management (convert from requirements.txt/pip to uv.lock/pyproject.toml)
2. Improve UI (modernize appearance, add new features/widgets, improve usability/accessibility)

## Steps

### Phase 1: UV Migration
1. Install uv if not present
2. Convert requirements.txt to pyproject.toml
3. Generate uv.lock file
4. Update build process to use uv
5. Test that the application still works with uv

### Phase 2: UI Improvements
1. Update stylesheet.qss for modern look
2. Enhance icons and assets
3. Improve layout and spacing
4. Add new UI features/widgets where appropriate
5. Improve accessibility (keyboard navigation, tooltips, error handling)

### Phase 3: Testing and Verification
1. Manual testing of core functionality
2. Verify PyInstaller build still works
3. Ensure all existing functionality remains intact

## Files to Modify
- requirements.txt → pyproject.toml
- assets/stylesheet.qss (UI improvements)
- build.bat (uv integration)
- main.py (potential updates for uv)
- Possibly newworld_config_manager/main_window.py for UI enhancements

## Dependencies
- uv (for dependency management)
- PyQt6 (existing dependency)

## Risks
- Breaking changes during UI updates
- Issues with uv integration
- Build process changes affecting PyInstaller

## Success Criteria
- Project successfully uses uv for dependency management
- Application builds and runs correctly with uv
- UI shows visible improvements in appearance and usability
- All existing functionality preserved
